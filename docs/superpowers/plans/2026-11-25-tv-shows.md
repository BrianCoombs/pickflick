# TV shows sessions — implementation plan (2026-11-25)

Foundation plan. Defines MediaType, the normalized `Title`, and media-type plumbing that the swipe-card,
pool-filters and session-settings plans build on. Follows docs shared decisions (2026-11-25) #1–#9.

## Verified facts (TMDb, prod DB read-only)
- Id spaces are separate: /movie/42009 = "Beatrice", /tv/42009 = "Black Mirror".
- /discover/tv list items: `name`, `first_air_date`, `genre_ids` (no `genres`), `vote_average`, `vote_count`,
  `poster_path`, `backdrop_path`, `origin_country`. Date filters are `first_air_date.gte/.lte`
  (NOT `primary_release_date.*`). `with_genres=35|18` = OR (252 results for 1990s, vote ≥ 7).
- /tv/{id}: `number_of_seasons`, `number_of_episodes` exclude specials (GoT: 8 / 73 while season 0 has 300;
  Black Mirror: 7 / 33). `episode_run_time` is often `[]`; `last_episode_to_air.runtime` exists (GoT 80).
  `tagline` may be "". `status` e.g. "Returning Series".
- `append_to_response=videos,watch/providers` works on /tv/{id}: response keys `videos` and `watch/providers`;
  `["watch/providers"].results.US.flatrate[]` = `{provider_id, provider_name, logo_path, display_priority}`
  (Netflix = 8, same ids as movies).
- /genre/tv/list (16): 10759 Action & Adventure, 16 Animation, 35 Comedy, 80 Crime, 99 Documentary, 18 Drama,
  10751 Family, 10762 Kids, 9648 Mystery, 10763 News, 10764 Reality, 10765 Sci-Fi & Fantasy, 10766 Soap,
  10767 Talk, 10768 War & Politics, 37 Western. Shared with movies: 16, 35, 80, 99, 18, 10751, 9648, 37.
- /tv/top_rated is dominated by anime/talk ("Dragon Ball Super: Beerus" first) → TV pools always use discover.
- Prod: 3 sessions (1 started, 2 completed), 6 cached_movies rows, 2 match_history rows.
- No history pages exist in app/; `getSessionHistory` has no caller. OMDb is never invoked (no imdbId passed) → untouched.

## Decisions
- Media type = column `movie_sessions.media_type` (decision #1), fixed at creation, never in preferences
  (updateSessionPreferences replaces the whole JSON).
- swipes / match_history need no media_type: within a session all ids share one type; match_history joins movie_sessions.
- Cache: `cached_movies.tmdb_id` keys become `movie:603` / `tv:42009` via `titleCacheKey`; value is the normalized
  `Title`. No migration; the 6 old bare-id rows are just never read (24 h TTL anyway).
- TV pools always via discover and always send `without_genres=10763,10767` (News, Talk); those two are not in the picker.
- Letterboxd hidden for TV (films only). Trakt uses `/sync/watchlist/shows` → `[{ show: { ids: { tmdb } } }]`
  (from Trakt docs; capture a real response as a fixture before relying on it).
- "Rent it" stays for TV (stores rented TV box sets).

## Normalized type — lib/titles/title.ts
```ts
export type MediaType = "movie" | "tv"

export interface TitleProvider { id: number; name: string; logoPath: string | null }

export interface Title {
  mediaType: MediaType
  id: number               // TMDb id within mediaType's id space
  key: string              // "movie:603" | "tv:42009" — React keys, cache keys
  name: string             // movie.title | tv.name
  overview: string
  posterPath: string | null
  backdropPath: string | null
  year: number | null      // yearOf(release_date | first_air_date)
  genres: { id: number; name: string }[]
  rating: number           // vote_average
  voteCount: number
  runtimeMinutes: number | null // movie: runtime || null; tv: episode_run_time[0] ?? last_episode_to_air?.runtime ?? null
  seasons: number | null   // tv: number_of_seasons; movie: null
  episodes: number | null  // tv: number_of_episodes; movie: null
  tagline: string | null   // "" → null
  trailerUrl: string | null      // first YouTube "Trailer" in appended videos
  providers: TitleProvider[]     // appended watch/providers, results[region].flatrate, sorted by display_priority
}
```

## Pure functions (lib/titles/*, each with a node:test file)
- `title.ts` — `parseMediaType(v: unknown): MediaType`
  - "tv"→"tv"; "movie", undefined, null, "TV", "film", 3 → "movie".
- `normalize.ts` — `yearOf(date)`, `movieToTitle(details)`, `tvToTitle(details)`, `providersFrom(raw, region = "US")`,
  `trailerFrom(videos)`. Fixtures in `lib/titles/__fixtures__/` (trimmed real responses): `movie-603.json`,
  `tv-42009.json` (Black Mirror, episode_run_time []), `tv-1399.json` (GoT, last_episode_to_air.runtime 80).
  - yearOf: "2000-01-01"→2000 (string slice, NOT `new Date()` — current code gives 1999 in US time zones);
    ""→null; null/undefined→null; "abcd"→null.
  - movieToTitle: title→name; runtime 0→runtimeMinutes null; seasons/episodes null; key "movie:603".
  - tvToTitle (42009): name "Black Mirror", year 2011, seasons 7, episodes 33, runtimeMinutes from
    last_episode_to_air or null, tagline "The future is bright.", key "tv:42009".
  - tvToTitle: tagline "" → null; missing number_of_episodes → null; episode_run_time [45] → 45.
  - same id 42009 as movie vs tv → different `key`.
  - providersFrom: US flatrate → [{id 8, "Netflix"}, …] sorted by display_priority; no US entry → [];
    missing "watch/providers" → [].
  - trailerFrom: picks YouTube+Trailer (prefers official); none → null; url `https://www.youtube.com/watch?v=KEY`.
- `format.ts` — `formatSeasonsEpisodes(seasons, episodes)`, `titleLengthLabel(t)`
  - (5, 62) → "5 seasons · 62 episodes"
  - (1, 8) → "1 season · 8 episodes"
  - (1, 1) → "1 season · 1 episode"
  - (2, 1) → "2 seasons · 1 episode"
  - (null, 10) → "10 episodes"; (0, 10) → "10 episodes"
  - (3, null) → "3 seasons"; (3, 0) → "3 seasons"
  - (null, null), (0, 0), (-1, NaN), (undefined, undefined) → null
  - titleLengthLabel: movie runtime 112 → "1h 52m" (reuses lib/store/format formatRuntime); movie runtime null → null;
    tv (5, 62) → "5 seasons · 62 episodes"; tv with runtime but no counts → null (TV never shows runtime).
- `cache.ts` — `titleCacheKey(mediaType, id)`: ("movie", 603) → "movie:603"; ("tv", 42009) → "tv:42009".
- `genres.ts` — `genresFor(mediaType)`, `sanitizeGenres(mediaType, ids)`, `TV_EXCLUDED_GENRES = [10763, 10767]`
  - genresFor("tv") has 14 entries, no 10763/10767; genresFor("movie") === MOVIE_GENRES.
  - sanitizeGenres("tv", [28, 35, 10765]) → [35, 10765]; ("movie", [10765, 28]) → [28]; dedupes; [] → [].
  - Used by `normalizePreferences(raw, mediaType)` in lib/sessions/preferences.ts (filters plan).
- `sources.ts` — `allowedSourceTypes(mediaType)`: movie → ["trakt", "letterboxd"]; tv → ["trakt"].
- lib/watchlists/trakt.ts (pure parts) — `traktWatchlistPath(mediaType)`: movie → "/sync/watchlist/movies",
  tv → "/sync/watchlist/shows"; `extractTraktTmdbIds(items, mediaType)`: reads `.movie` / `.show`, drops null/absent
  tmdb ids, ignores items of the other kind. Fixture `lib/watchlists/__fixtures__/trakt-watchlist-shows.json`.
- `copy.ts` — `mediaCopy(mediaType)`; test: both types have every key, all non-empty, movie strings equal today's copy.

## How this connects to the other plans
- Swipe card: renders only `Title` fields (`overview`, `titleLengthLabel(t)`); Swiper keyed by poolVersion.
- Pool filters: owns `SessionPreferences`, `normalizePreferences(raw, mediaType)` (calls `sanitizeGenres`),
  `discoverQuery(mediaType, prefs)` (must use `first_air_date.*` and `without_genres` for tv), `with_watch_providers`
  (provider ids are shared between movie and tv).
- Session settings: add-more uses `getTitlePool({ mediaType: session.mediaType, prefs, exclude: pool })`;
  all-matches results use `getEnrichedTitle`; summary shows media type via `mediaCopy`; WaitingCounter uses `mediaCopy`.

## Risks
- 50 `getTitle` calls per session page load (unchanged count; providers now ride on the same call).
- Strict zod on TV details (null tagline/counts for new shows) — schemas must be lenient.
- TV year filter = premiere year; long-running shows won't appear in later decades.
- Trakt shows response shape unverified until captured.
- Saved preferences with letterboxd sources or movie genre ids on a TV session — filtered server-side.
- Deploy before migration would break inserts/selects of `media_type` — migration first.
